Android

Celular ou tablet · Android 7 ou mais novo

Baixar para Android
  1. Toque em Baixar para Android e abra o arquivo Makall.apk.
  2. Se o Android pedir, permita instalar apps desta fonte (só para o navegador que você usou).
  3. Toque em Instalar. Pronto!

Já tem o Makall? Baixe e instale por cima: suas conversas continuam lá.

💻

Windows

PC ou notebook · Chrome ou Edge

Instalar no PC
  1. Clique em Instalar no PC: o Makall abre numa aba nova.
  2. Na barra de endereço, clique no ícone Instalar ⊕ (ou no menu ⋮ → Instalar Makall).
  3. Pronto: o Makall ganha ícone na área de trabalho e abre em janela própria.

Leve, sem arquivo para baixar, e se atualiza sozinho sempre que sair versão nova.

🐧

Linux

Ubuntu, Linux Mint, Debian, Pop!_OS, Zorin · 64 bits

Baixar para Linux
  1. Clique em Baixar para Linux e abra o arquivo Makall.deb com dois cliques.
  2. Na tela de instalação, clique em Instalar e digite a senha do computador. (Pelo terminal: sudo apt install ./Makall.deb)
  3. Pronto: o Makall aparece no menu de aplicativos.

Usa Fedora, Arch ou outro? Instale pelo navegador (Chrome, Chromium, Edge ou Brave): funciona igual e se atualiza sozinho.
